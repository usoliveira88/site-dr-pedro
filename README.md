# Site institucional Dr. Pedro Machado

Projeto em Next.js com Tailwind CSS, responsivo, componentizado e preparado para edição posterior.

## Como rodar localmente

```bash
npm install
npm run dev
```

Depois abra:

```bash
http://localhost:3000
```

## Campos pendentes de edição humana

Os dados abaixo estão propositalmente como placeholders para evitar publicação de informações não validadas:

- CRM e RQE oficiais
- WhatsApp, telefone ou link de agendamento
- Endereço completo do consultório
- Horários de atendimento
- Formação, títulos, especialidades e credenciais
- Escopo real dos atendimentos
- Textos finais de bio e filosofia clínica
- Vídeo institucional
- Vídeos específicos por serviço
- Mapa, fotos do consultório e links de redes sociais
- Imagem conceitual final do Hero da Home

## Observações de conteúdo

- A foto real do Dr. Pedro aparece apenas nos blocos de Bio/Sobre.
- O Hero da Home usa uma imagem conceitual provisória em `public/images/hero-wellness-placeholder.svg`.
- A comunicação evita promessas clínicas e usa linguagem informativa.
- O conteúdo sensível deve ser revisado antes da publicação.
